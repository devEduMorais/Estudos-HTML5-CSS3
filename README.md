#Links de ferramentas úteis para design:  
    Adobe Color: color.adobe.com - Útil para estudar e brincar com círculo cromático, pegar códigos de cor, e pegar configurações rápidas de cor e paletas

    Paletton: paletton.com       - Ajuda além de montar a paleta, ele monta um exemplo utilizando as cores, para pré visualização com o page layout.

    Coolors: coolors.co          - Ao entrar, ele já te ajuda a criar paletas de sugestão, podendo travar cores, e o algoritmo auxilia  sugerindo cores que combinem com a paleta.

    WhatFontIS: whatfontis.com - site pra detectar a fonte passada uma imagem
